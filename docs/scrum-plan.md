# План проекта Motor Portal

Учебная модель Scrum для разработки аналога Motor.ru. Репозиторий содержит документы и демонстрационные изменения лабораторной №2.

- 24 спринта по две недели, 96 пакетов работ.
- Базовая оценка 4473 чел.-ч., резерв 727 чел.-ч., бюджет 5200 чел.-ч.
- Роли: Product Owner, Backend developer / Scrum Master, Frontend / UX, QA / DevOps.
- Выпуски: v0.1, v0.2, v0.3, v0.4, v0.5, v1.0.
- Этапы: Backlog → To Do → In Progress → Code Review → Testing → Done.

## Первый инкремент

Читатель открывает тестовую новость на стенде. Страница содержит заголовок, дату и текст, доступна по постоянному адресу и читается на мобильном экране. Неизвестный адрес возвращает понятную ошибку.

## Критерии готовности

Результат прошёл ревью и проверки, замечания устранены, документация обновлена. Учебная симуляция статусов и трудозатрат не означает фактическую реализацию всего портала.
